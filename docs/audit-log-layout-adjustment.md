# 审计日志页面布局调整记录

本文记录 `src/views/audit/AuditLogList.vue` 的调整过程和最终约定，供后续列表页、日志页、统计型页面参考。

## 背景

审计日志页最初采用本项目既有列表页样式，但用户要求参考 `sub2api/frontend` 的使用记录页面显示方式进行优化。后续又结合当前项目的产品管理页布局，将筛选区、操作区和统计区调整为更符合本项目通用列表页的结构。

参考来源：

- `sub2api/frontend/src/views/user/UsageView.vue`
- `sub2api/frontend/src/components/common/DateRangePicker.vue`
- `web/src/views/product/ProductList.vue`

## 调整过程

1. 首先参考 `sub2api` 使用记录页，将审计日志页改为“统计卡片 + 筛选区 + 表格”的信息结构。
2. 统计卡片从原先独立散落的卡片调整为顶部 4 个紧凑指标卡：总记录数、创建、更新、删除。
3. 表格单元格增强了可读性：操作类型使用轻量 badge，时间拆分为日期和时间两行，用户列增加用户图标，对象文本允许换行，对象 ID 和 IP 使用等宽小字。
4. 时间范围从两个原生日期输入改成 `DateRangePicker`，并对齐 `sub2api` 的快捷范围弹层样式。
5. 时间范围默认值对齐使用记录页：最近 7 天，也就是当天往前 6 天到当天。重置筛选时同样恢复最近 7 天。
6. 删除主筛选区中重复的用户 ID、对象 ID、IP 地址输入，因为这些已经被通用搜索覆盖。
7. 将“导出”和“导出记录”文案改为“导出日志”和“导出历史”，避免误解为重复功能。
8. 参考产品管理页，将刷新、导出日志、导出历史放到页面右上角操作区；刷新按钮只保留图标，并在加载时旋转。
9. 参考产品管理页，将筛选区改为 `FilterRow` 扁平布局，放在统计卡片上方，不再使用筛选卡片外壳，也不显示字段标题。
10. 通用搜索调整为筛选区第一个控件，后面依次是操作类型、对象类型、时间范围、重置。

## 最终布局

最终页面顶部顺序如下：

1. 右上角操作区
   - 刷新：仅图标，`loading` 时旋转。
   - 导出日志：发起新的审计日志导出任务。
   - 导出历史：查看历史导出任务并下载文件。
2. 筛选区
   - 通用搜索。
   - 操作类型。
   - 对象类型。
   - 时间范围。
   - 重置。
3. 统计卡片
   - 总记录数。
   - 创建。
   - 更新。
   - 删除。
4. 数据表格。
5. 分页。

## 可复用约定

### 操作区

列表页右上角操作区优先放在 `TablePageLayout` 的 `#actions` 中，参考 `ProductList.vue`。

- 刷新按钮只保留图标时必须提供 `title="刷新"`。
- 刷新按钮在 `loading` 时使用 `animate-spin`。
- 导出类按钮使用 `btn btn-secondary`，并配合 `download` 图标。
- 多个导出入口要用明确文案区分动作，例如“导出日志”和“导出历史”。

### 筛选区

常规列表页筛选区优先使用 `FilterRow`。

- 通用搜索放在最前面。
- 不显示额外 label，依靠 placeholder 表达字段含义。
- 避免在主筛选区放和通用搜索重复的精确筛选项。
- 重置按钮放在筛选控件末尾，而不是右上角操作区。

### 时间范围

有时间范围筛选的日志类页面优先使用 `DateRangePicker`。

- 默认最近 7 天。
- 变更时间范围后应刷新列表和统计卡片。
- 重置筛选后应恢复默认最近 7 天。
- 统计接口应携带当前筛选条件，避免统计卡片与表格范围不一致。

### 统计卡片

审计日志目前保留页面内定制统计卡片，因为其指标和 `sub2api` 使用记录页接近，需要显示图标块、主数值和辅助说明。

后续模块如果是标准摘要指标，应优先使用 `StatsCards`；如果需要完全复刻 `sub2api` 使用记录页这种展示方式，可以参考审计日志页当前写法。

### 表格单元格

日志类表格应优先强化扫描效率：

- 时间可拆分为日期和时间两行。
- 操作类型使用语义色 badge。
- 长对象名称允许换行，避免撑宽表格。
- ID、IP、编码类内容使用等宽字体。
- 变更字段等集合值使用紧凑标签展示。

## 注意事项

- 审计日志导出弹窗和导出历史弹窗中的筛选项没有跟随主筛选区精简，它们属于独立任务管理流程，不等同于列表主筛选。
- `DateRangePicker` 是共享组件，本次样式对齐会影响其他使用它的页面；改动时需同时检查施工单等已有日期范围筛选页面。
- 如果后续新增日志类页面，应优先复用审计日志页的最终结构，而不是复用调整过程中的中间版本。
