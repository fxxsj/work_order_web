# 审计日志页面规范

本文说明 `src/views/audit/AuditLogList.vue` 的当前布局和可复用约定，供后续列表页、日志页、统计型页面参考。

## 页面布局

审计日志页顶部顺序如下：

1. 右上角操作区
   - 刷新：仅图标，`loading` 时旋转。
   - 导出日志：发起新的审计日志导出任务。
   - 导出历史：查看导出任务并下载文件。
2. 筛选区
   - 通用搜索。
   - 操作类型。
   - 对象类型。
   - 时间范围。
   - 重置。
3. 统计卡片
   - 总记录数。
   - 创建。
   - 更新。
   - 删除。
4. 数据表格。
5. 分页。

## 操作区

列表页右上角操作区优先放在 `TablePageLayout` 的 `#actions` 中。

- 刷新按钮只保留图标时必须提供 `title="刷新"`。
- 刷新按钮在 `loading` 时使用 `animate-spin`。
- 导出类按钮使用 `btn btn-secondary`，并配合 `download` 图标。
- 多个导出入口要用明确文案区分动作，例如“导出日志”和“导出历史”。

## 筛选区

常规列表页筛选区优先使用 `FilterRow`。

- 通用搜索放在最前面。
- 不显示额外 label，依靠 placeholder 表达字段含义。
- 避免在主筛选区放和通用搜索重复的精确筛选项。
- 重置按钮放在筛选控件末尾，而不是右上角操作区。

## 时间范围

有时间范围筛选的日志类页面优先使用 `DateRangePicker`。

- 默认最近 7 天。
- 变更时间范围后应刷新列表和统计卡片。
- 重置筛选后应恢复默认最近 7 天。
- 统计接口应携带当前筛选条件，避免统计卡片与表格范围不一致。

## 统计卡片

审计日志保留页面内定制统计卡片，用于显示图标块、主数值和辅助说明。

标准摘要指标优先使用 `StatsCards`。只有当页面需要专属指标结构时，才在页面内定制统计卡片。

## 表格单元格

日志类表格应优先强化扫描效率：

- 时间可拆分为日期和时间两行。
- 操作类型使用语义色 badge。
- 长对象名称允许换行，避免撑宽表格。
- ID、IP、编码类内容使用等宽字体。
- 变更字段等集合值使用紧凑标签展示。

## 注意事项

- 审计日志导出弹窗和导出历史弹窗中的筛选项属于独立任务管理流程，不等同于列表主筛选。
- `DateRangePicker` 是共享组件，改动时需同时检查施工单等已有日期范围筛选页面。
- 新增日志类页面时优先复用本页结构。
